# 🎬 OnlineCinema — Cross-Platform Web & Mobile App

Кроссплатформенное приложение (Web / Android / iOS) для онлайн-кинотеатра с элементами социальной сети. Проект разработан в качестве дипломной работы (MVP).

> 📱 **Обратите внимание:** Этот репозиторий содержит клиентскую (Frontend) часть приложения.  
> ⚙️ Исходный код бэкенда (Node.js / Express API) находится в репозитории: [OnlineCinema Backend](https://github.com/Nickaykr/my-server).

## 🚀 Основные возможности

* **Каталог фильмов:** Просмотр списка фильмов, удобный поиск и фильтрация по жанрам.

## 📦 Инструкция по локальному запуску

### Предварительные требования
* **Node.js** (версия 18.x или выше)
* **npm** или **yarn**
* Для мобильного запуска: приложение **Expo Go** на телефоне или настроенный эмулятор (Android Studio / Xcode)

### Шаги установки

1. **Клонируйте репозиторий:**
   ```bash
   git clone [https://github.com/Nickaykr/OnlineCinema.git](https://github.com/Nickaykr/OnlineCinema.git)
   cd OnlineCinema

2. Установите зависимости:
```bash
npm install
```

3. Настройте переменные окружения (создайте файл `.env` в корне проекта):
```env
EXPO_PUBLIC_API_URL=http://localhost:5000/api
```

4. Запустите проект:
```bash
npx expo start
```

---

### Варианты запуска

* **В десктопном браузере (Web):** Нажмите **`w`** в терминале после запуска.
* **На телефоне (Expo Go):** Отсканируйте QR-код из терминала через приложение Expo Go.
* **На эмуляторе Android:** Нажмите **`a`** в терминале.
