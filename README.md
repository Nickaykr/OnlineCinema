# 🎬 OnlineCinema — Cross-Platform Web & Mobile App

Кроссплатформенное приложение (Web / Android / iOS) для онлайн-кинотеатра с элементами социальной сети. Проект разработан в качестве дипломной работы (MVP).

> 📱 **Обратите внимание:** Этот репозиторий содержит клиентскую (Frontend) часть мобильного приложения.  
> ⚙️ Исходный код бэкенда (Node.js / Express API) находится в репозитории: [OnlineCinema Backend](https://github.com/Nickaykr/my-server).

## 🚀 Основные возможности

* **Каталог фильмов:** Просмотр списка фильмов, поиск, фильтрация по жанрам и категориям.
* **Детальная страница фильма:** Информация о картине, актерском составе и рейтинге.
* **Социальное взаимодействие:** Добавление пользователей в друзья, просмотр списков избранного и списков «Посмотреть позже» у друзей.
* **Личный кабинет:** Управление профилем, подпиской и индивидуальными списками фильмов.
